# MT Travel generated image set

Generated with Codex's built-in image-generation tool on August 2, 2026. All files are project-local JPEG derivatives sized for the app. No external image-generation API was used.

## Shared prompt direction

Activity images used this prompt pattern:

> Wide 16:9 photorealistic editorial travel photograph of the named Canadian Rockies location in early October, with geographically recognizable scenery, natural light, believable seasonal conditions, no logos, no readable text, and no watermark. Designed as a clear itinerary or activity-card preview.

The pattern was applied separately to Lake Agnes Tea House, Little Beehive, Banff Gondola, Banff Upper Hot Springs, Johnston Canyon Upper Falls, Lake Minnewanka, Cave and Basin, Peyto Lake, Columbia Icefield, Policeman's Creek, Grotto Canyon, Grassi Lakes, Athabasca Falls, Pyramid Lake and Island, Maligne Lake, and downtown Jasper.

Lodging images used this prompt pattern:

> Wide 16:9 photorealistic travel-planning illustration of a generic lodging style in Banff, Canmore, or Jasper in early October, with fitting mountain architecture and scenery, no real-property branding, no logos, no signs, no readable text, and no watermark. This is an illustrative preview, not a depiction of a specific property.

Distinct lodging prompts covered a Banff alpine hotel exterior, a modern Banff suite, a Canmore group condo, a Jasper alpine lodge, a walkable modern central Jasper hotel, a Jasper wellness lodge, and a Pyramid Lake-style lakeside lodge.

## Product-use rule

Generated lodging art must always be labeled **Illustrative preview**. It must never be described as a real property photo. Each lodging card must keep its direct official-property link so travelers can verify real photos, live inventory, room layouts, fees, and cancellation terms.
